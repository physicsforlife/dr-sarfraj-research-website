# SEO steps after publishing the website

The HTML now includes a descriptive page title, meta description, crawl directives, social-sharing metadata, a favicon, and Person structured data linking Dr. Mujawar's established scholarly profiles.

## After you choose the final GitHub Pages address

1. Publish the site on GitHub Pages and copy the exact public URL.
2. Add a canonical URL in `index.html` using that exact URL. Also add absolute `og:url` and `og:image` URLs; the image URL should point to `assets/professor-portrait.jpg` on the live site.
3. Create `sitemap.xml` containing the exact homepage URL and create `robots.txt` with a `Sitemap:` line pointing to the live sitemap URL. Because the final GitHub Pages address is not known yet, these files should be generated only after the URL is chosen.
4. Add the site as a URL-prefix property in Google Search Console and complete its verification steps.
5. Submit the sitemap in Search Console, then use URL Inspection to request indexing of the homepage.
6. Once the site is live, add its URL to the Homepage field in Dr. Mujawar's Google Scholar profile if he approves.
7. Recheck the site on mobile and desktop and test all internal and external links.

## Important

Indexing and ranking are controlled by Google and are not guaranteed or immediate. Avoid keyword stuffing and do not pay for unsolicited promises of first-place ranking. Keep names, positions, publication metadata and recognition descriptions accurate. Obtain approval before publishing student information or other personal material.
